# Vectora model family

Vectora documents educational language-model implementations and their
versioned technical records. Each release has its own page, evidence scope,
diagrams, and reproducibility notes.

## Available versions

- [Vectora v1](/models/vectora/v1) — A documented educational decoder-only
  Transformer using GPT-2 tokenization. The supplied notebook describes a
  randomly initialized model and demonstrates a forward pass and greedy
  generation. It does not show model training or measured language-model
  quality.

- [Vectora v1.1](/models/vectora/v1.1) — An experimental character-level
  GPT-style Transformer trained from scratch on a subset of Shakespeare text.
  Unlike v1, this version includes a complete training pipeline, recorded loss
  metrics, and generated text samples.

Future versions will be added only when their documentation is supplied.
