# Vectora model family

Vectora documents educational language-model implementations and their
versioned technical records. Each release has its own page, evidence scope,
diagrams, and reproducibility notes.

## Available versions

The only version currently documented is [Vectora v1](/models/vectora).
Its supplied notebook describes a randomly initialized educational
decoder-only Transformer and demonstrates a forward pass and greedy
generation. It does not show model training or measured language-model
quality.

Future versions will be added only when their documentation is supplied.
