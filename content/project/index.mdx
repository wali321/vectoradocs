title: Vectora
description: >-
  Vectora is an independent language-model project built to make the mechanics
  of language modeling concrete. It explores how a model turns text into token
  IDs, processes those tokens through neural-network components, and produces
  next-token predictions. The project develops these ideas through direct
  implementation in Python and PyTorch rather than treating a hosted model API
  as a black box.
---

## Project overview

Vectora is organized around model versions. Each version is a specific
implementation with its own architecture, configuration, and development
status; details from one version should not be assumed to describe another.
The project-level aim is to learn by building and examining the components
that make language models work.

The project encompasses three independently documented releases:
- **Vectora v1**: A foundational decoder-only Transformer architecture using GPT-2 subword tokenization with randomly initialized weights to study tensor shapes and autoregressive data flow.
- **Vectora v1.1**: An experimental character-level GPT-style Transformer trained from scratch on a 500k-character Shakespeare subset, featuring a complete training pipeline, recorded loss curves, and top-k character generation.
- **Vectora v1.2**: A 23M dataset experiment scaling character-level GPT training across the full 82.2M-character corpus (~23.4M estimated GPT-2 tokens) over 50,000 steps with an expanded 333-character vocabulary and lower validation loss.

## Research and engineering direction

The current work focuses on the mechanics of autoregressive language models:
tokenization, embeddings, causal attention, Transformer blocks, training dynamics,
and text generation.

- **Architecture exploration (v1)**: Demonstrated 4-block, 256-width decoder-only Transformer layers with GPT-2 BPE tokenization and greedy autoregressive decoding.
- **Training and character modeling (v1.1)**: Implemented an end-to-end training pipeline on 450,000 Shakespeare training characters with AdamW optimization, cosine learning-rate decay, gradient clipping, periodic validation, and temperature-controlled top-k sampling.
- **Dataset scaling and representation stability (v1.2)**: Scaled pretraining to 73.99 million training characters (82.22M total) across 50,000 steps, evaluating loss convergence and character representation stability on an expanded 333-character vocabulary without subwords.

## Current project status

The available files support a transparent status description:

1. **Vectora v1** has a notebook implementation that constructs the model, runs a forward pass, and demonstrates greedy token generation using randomly initialized weights. It serves as an architectural baseline.
2. **Vectora v1.1** is a trained model checkpoint (`fcc.pt`) and notebook implementation with 10,000 recorded optimization steps, reducing cross-entropy loss from 4.42 down to 1.37 (train) and 1.48 (val).
3. **Vectora v1.2** is a completed 50,000-iteration pretraining experiment on the full 82.2M-character dataset (~23.4M estimated GPT-2 tokens), reducing cross-entropy loss to 1.3793 (train) and 1.4082 (val) across an expanded 333-character vocabulary, demonstrating coherent syntax and prose generation.

## Future direction

Possible directions for future releases include subword tokenization (Byte-Pair Encoding),
larger context windows beyond 128 tokens, parameter scaling, curated multidomain datasets,
standardized perplexity benchmarks, and instruction fine-tuning.
