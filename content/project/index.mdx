Vectora is an educational machine-learning project for exploring how language
models are assembled and documented. Its published work currently includes
Vectora v1, a small GPT-style Transformer implementation.

## Project purpose

The project makes model components, data flow, and implementation limits
readable as part of the research record. The site separates project-wide
context from version-specific technical details so later releases can be
understood on their own terms.

## Research direction

Vectora's documentation emphasizes explaining implementation choices,
recording reproducibility constraints, and distinguishing demonstrated
behavior from planned work. Claims about training, evaluation, and model
quality are included only when supported by project evidence.

## Published versions

- [Vectora v1 technical documentation](/models/vectora) — an
  evidence-based record of the supplied educational Transformer notebook,
  including its architecture, inference path, limitations, and references.

No later version has been supplied. Future releases will have independent
documentation and assets rather than inheriting v1 specifications or diagrams.
